# Replication: *The Savings of Corporate Giants*

**Empirical Methods — Problem Set 3 (UZH, HS 2026)**  
Paper: Olivier Darmouni and Lira Mota, *The Savings of Corporate Giants*, *The Review of Financial Studies* (2024).  
Authors' replication package: https://doi.org/10.7910/DVN/KDFUHV

## Goal

Reproduce **Table 2, Panel A, Column (1)** using a difference-in-differences regression with firm and year fixed effects. Compare conventional IID and firm-clustered standard errors.

## Files

| File | Purpose |
|---|---|

## Run in RStudio

1. Extract the ZIP, preserving the folders.
2. Open `Corporate_Giants_Replication.Rproj` in RStudio.
3. Open `run_replication.R` and click **Source**, or run:

   ```r
   source('run_replication.R')
   ```

4. The script installs any missing packages: `DBI`, `RPostgres`, `rstudioapi` and `fixest`.
5. **First run only:** If the WRDS extracts are not already present, enter your own WRDS username and password when prompted; a valid authorized institutional account is required. The password is not written to disk by this script.
6. Inspect the console output and the files under `output/`.

For convenience, RStudio users can specify their username only for the current session before running:

```r
Sys.setenv(WRDS_USER = 'your_username')
```

Never put a WRDS password in a shared script or repository. Data licensing may restrict sharing the downloaded Compustat extracts and the RDS files produced from them. Share the code and aggregate regression tables; verify your institution's permissions before sharing restricted records.

## Methodological qualifications

- The script is a structured version of **our group's workflow**, not an exact port of the full authors' code. The published sample has **one more observation**; matching counts alone does not prove the same firm-years are included.
- Authors' `year` is matched to Compustat `fyear`. Timing differences can influence results.
- Company SIC/NAICS codes are used as fallbacks where historical codes are missing. This choice should be checked against the authors' filtering logic.
- Individual missing hand-collected bond-category values are set to zero, but missing Compustat balances are **not** generally set to zero.
- The payout and foreign-income variables are constructed as in the team's exploratory script; the exact authors' processed `fdata.rds` may contain additional transformations.
- This script covers **only** Table 2, Panel A, Column (1), plus a clustered-SE robustness comparison. Other requested outputs (figures, critical evaluation) must be prepared separately.
